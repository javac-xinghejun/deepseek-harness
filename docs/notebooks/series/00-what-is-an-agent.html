第 00 讲 · 什么是 Agent

模型 + 循环 + 工具 —— 全系列的起点，不含任何 dsh 内容

这一讲记住一句话

  • • 模型只负责决策：给出回答，或申请调用某个工具
  • • harness 负责其余一切：真正执行工具、维护上下文、判断何时结束

为什么需要 harness

  • • 模型没有手：不能读文件、跑命令、上网
  • • 模型没有记忆：每次请求都要把全部材料重新喂给它
  • • 循环、工具执行、停止条件，都得有人管

两个常见误解

  • • ✗「agent 是一个更聪明的模型」——它是同一个模型 + 一个工程化的循环
  • • ✗「工具是模型执行的」——模型只发指令，动手的始终是 harness
