# 图解系列 · 从零看懂 DeepSeek Harness

> 个人学习笔记，不是产品文档。本系列为同一个终点服务：**基于 dsh 打造一个垂直领域、操作本机资源、双击安装的桌面 agent**（Electron 薄壳，Windows 先行、macOS 跟上）。

## 学习方式

- **边读边动手**：每讲配一个动手任务，验证标准写在任务卡里，跑通才算学完。
- **代码任务的分工**：小代码（如第 06 讲的 10 行插件）建议自己敲；大代码你可以写伪代码让 AI 补全——每个代码任务卡附「验收清单」，最终以运行结果为准。
- **你的代码写在哪里**：`~/.dsh/profiles/<你的profile>/`（dsh 的 out-of-tree 插件路径），永远不进本仓库的 `packages/`。
- 每讲约 30–60 分钟，随时中断随时续。

## 固定视觉语言

所有图共用一套颜色语义，看到颜色就知道类别：青 = 人 / 入口，绿 = harness 核心服务，橙 = 工具与 seam 接口，紫 = 数据，玫红 = 安全约束，灰 = 外部世界。每图不超过 8 个元素，编号 ①②③ 与对应 MD 详解一一对应。
