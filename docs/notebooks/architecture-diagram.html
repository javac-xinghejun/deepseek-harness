DeepSeek Harness Architecture

everything is a plugin —— vendored Cordis 插件树上的 agent 运行时

一切皆插件

  • • vendor/ 的 Cordis：context 是服务仓库，服务按 ctx key 相互发现
  • • inject 声明依赖，加载顺序自动求解
  • • 注册即可逆 effect，插件卸载即回卷
  • • waterfall 监听器必须 next() 委托，否则短路

三角色 capability seam

  • • Service Definition 声明接口，Provider 实现，Consumer 使用
  • • Provider 可整体替换：local ↔ E2B 远程执行世界
  • • Consumer 多为模型工具（tool-bash、tool-fs…）
  • • 换一个 provider，bash / PTY / LSP 一起搬家

日志即真相

  • • append-only SessionEvent 流是唯一事实源
  • • model-visible ⟺ logged 由运行时不变量断言
  • • deriveMessages() 从日志投影模型历史
  • • fork / resume / 回放 / 遥测全部从这条流派生
